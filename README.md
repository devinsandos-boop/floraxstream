# Flora & Stem

Responsive multi-page flower shop website built with plain HTML, CSS, and JavaScript.

Open `index.html` in a browser to start. The included pages are:

- `index.html` — Home
- `shop.html` — Product listing with category filters
- `about.html` — Brand story
- `contact.html` — Contact form interaction

All pages are static and can be deployed to GitHub Pages, Netlify, or AWS Amplify without a build step.
